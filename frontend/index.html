Transparency & privacy

Data & method

Where your account data goes and how the estimates work.

Data sources

Dashboard sample rows are generated locally in the browser. No device sensors, browsing history, screen content, or external data sources are used.

Your account’s activities, goals, tasks, habits, reflections, and preferences are stored per account in DynamoDB and cached on this device. Sign in on another device to sync them.

Cloud services

Amazon Cognito handles account sign-in. Authenticated API requests use API Gateway and Lambda; each account’s app data is stored separately in DynamoDB.

S3 stores the website files and CloudFront serves them over HTTPS. Amazon SES can send a weekly summary on demand when you choose that action.

How to interpret the scores

Dashboard scores are simple illustrative calculations, not predictions from the trained Python model, diagnoses, or validated behavioral insights.

Exam demonstration

The Python project demonstrates synthetic data generation, validation, feature engineering, local model training, evaluation, experiment tracking, quality gating, artifact versioning, and retraining. The dashboard does not send personal journal data to the model.
